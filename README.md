# Эмулятор командной строки с виртуальной файловой системой (VFS)

Консольное приложение на C# (.NET), эмулирующее работу базовой командной строки UNIX-подобной операционной системы[cite: 24, 27]. Файловая система полностью хранится и модифицируется в оперативной памяти и инициализируется на основе структуры из CSV-файла[cite: 24, 26].

---

## Возможности проекта

* **Древовидная файловая система в памяти:** поддержка каталогов и файлов с произвольной глубиной вложенности без сохранения изменений обратно на физический диск[cite: 25, 26].
* **Гибкая навигация:** поддержка абсолютных путей (начинающихся с `/`), относительных путей, а также спецсимволов `.` (текущая директория) и `..` (родительская директория)[cite: 23].
* **Два режима работы:** интерактивный ввод команд пользователем и автоматический пакетный запуск команд из стартового скрипта.
* **Декодирование содержимого:** бинарные и текстовые файлы хранятся в байтах и преобразуются в читаемый вид (UTF-8) при выводе[cite: 25, 27].
* **Глубокое копирование:** дублирование файлов и рекурсивное копирование директорий с изоляцией состояния и защитой от зацикливания[cite: 25, 26].

---

## Архитектура системы

Проект разделен на слабосвязанные модули:

* **`Program.cs`** — точка входа в программу. Выполняет разбор аргументов запуска (`--vfs`, `--script`), инициализирует VFS, управляет чтением скрипта тестирования и циклом ожидания ввода.
* **`VfsNode.cs`** — узел виртуальной файловой системы[cite: 25]. Содержит флаг типа (файл/каталог), имя, байтовый массив `Content`, ссылку на родителя `Parent` и словарь дочерних элементов `Children`[cite: 25]. Предоставляет метод `Clone()` для создания независимой копии узла[cite: 25].
* **`VirtualFileSystem.cs`** — управление состоянием файловой структуры. Хранит указатели на корень (`Root`) и текущую директорию (`CurrentDirectory`), парсит CSV-файл для построения первичного дерева, формирует prompt и реализует операции `ChangeDirectory` и `Copy`.
* **`PathResolver.cs`** — статический сервис вычисления пути[cite: 23]. Пошагово проходит по узлам дерева от корня или текущей позиции, возвращая целевой `VfsNode` или `null` при ошибке[cite: 23].
* **`CommandExecutor.cs`** — диспетчер команд[cite: 27]. Выполняет проверку количества аргументов, валидирует типы объектов (каталог/файл) и выводит ошибки[cite: 27].
* **`Parser.cs` / `ParsedCommand.cs`** — лексический разбор строки ввода на имя команды и массив аргументов[cite: 29, 30].
* **`EmulatorConfig.cs`** — неизменяемая структура параметров конфигурации запуска[cite: 28].

## Поддерживаемые команды

| Команда | Описание | Обработка ошибок |
| :--- | :--- | :--- |
| **`cd [путь]`**[cite: 27] | Смена текущей рабочей директории[cite: 26, 27]. Без аргументов возвращает в корень `/`[cite: 26, 27]. | Ошибка, если путь не найден, объект является файлом или передано более 1 аргумента[cite: 26, 27]. |
| **`ls [путь]`**[cite: 27] | Просмотр содержимого каталога (или имени одиночного файла)[cite: 27]. По умолчанию выводит текущую директорию[cite: 27]. | Ошибка при обращении к несуществующему файлу или каталогу[cite: 27]. |
| **`tail <файл>`**[cite: 27] | Вывод последних 10 строк указанного файла в кодировке UTF-8[cite: 27]. | Ошибка при отсутствии аргумента, несуществующем файле или попытке прочитать каталог[cite: 27]. |
| **`rev <файл>`**[cite: 27] | Построчный реверс символов текста с сохранением исходного порядка строк[cite: 27]. | Ошибка при отсутствии аргумента, несуществующем файле или попытке чтения директории[cite: 27]. |
| **`cp <источник> <назначение>`**[cite: 27] | Копирование файлов/папок внутрь существующего каталога или с переименованием. | Ошибка при отсутствии источника, неверном родительском каталоге назначения или попытке скопировать каталог внутрь самого себя. |
| **`exit`** | Завершение работы эмулятора или прерывание пакетного файла[cite: 24]. | — |

## Формат файла конфигурации VFS (CSV)

Виртуальная файловая система загружается из CSV-файла со следующей структурой[cite: 26]:

```csv
Path,Type,Content
/,dir,
/docs,dir,
/docs/sub,dir,
/docs/notes.txt,file,SGVsbG8gV29ybGQKMTIzNDUKQWJjIGRlZg==
/biglog.txt,file,TGluZSAwMTogdGVzdA==
